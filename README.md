Esta app es el proyecto final del curso dictado por CoderHouse.

Para ejecutarlo localmente se debe tener instalado Node "npm install" y en consola escribir: "npx expo start".
Una vez cargado, se puede escanear el QR desde el celular con la aplicacion Expo Go. Puedes apretar la letra "a" y correrlo en un emulador que hayas descargado y configurado. O tambien puedes correrlo en un navegador web al apretar "w", pero para ello debes instalar lo siguiente: "npx expo install react-dom react-native-web"

La pantalla principal muestra el listado de tareas, y en caso de no haber, un mensaje notificandolo. 
- En ella existe un boton donde te envia a otra pantalla (navegacion stack), donde se puede crear una nueva tarea mediante un formulario. Se regresa a la pantalla de inico a partir del guardado de la tarea creada o al presionar sobre una flecha. 
- En HomeScreen tambien existe una barra horizontal que permite una navegacion tab hacia la pantalla de perfiles. La opción correspondiente a la página actual, posee el color negro.
