Esta app es el proyecto final del curso dictado por CoderHouse.

Para ejecutarlo localmente se debe tener instalado Node "npm install" y en consola escribir: "npx expo start".
Una vez cargado, se puede escanear el QR desde el celular con la aplicacion Expo Go. Puedes apretar la letra "a" y correrlo en un emulador que hayas descargado y configurado. O tambien puedes correrlo en un navegador web al apretar "w", pero para ello debes instalar lo siguiente: "npx expo install react-dom react-native-web"

En este momento el proyecto esta en la etapa 2, donde se crearon carpetas dedicadas y archivos principales con la idea que sean reutilizables. 
Se crearon dos Screen, donde ambas son funcionales pero solo una se muestra, ya que aun no se tiene conocimiento suficiente para la navegacion entre ellas.
La que se muestra, posee las ProfileCards como se lo solicita. Tambien se hace uso de Theme para colores y margenes reutilizados en las diferentes screen.
Por ahora los archivos son muy basicos cumpliendo una funcion mas de tipo conceptual.
